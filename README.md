# ebpm_postmortem

Postmortem server for EBPMs

This is where you should write a short paragraph that describes what your module does,
how it does it, and why people should use it.

Source          | <https://gitlab.diamond.ac.uk/controls/ioc/CS/cs-di-ioc-08>
:---:           | :---:
Docker          | `docker run ghcr.io/diamondlightsource/CS-DI-IOC-08:latest`
Releases        | <https://gitlab.diamond.ac.uk/controls/ioc/CS/cs-di-ioc-08/releases>

## Running

```
python -m ebpm_postmortem
```

Use flag `-D` to run in debug mode.
